# Redline

Open-source Linux GPU control and gaming dashboard by **Slave IT Solutions** — info@slave.gr.

A native Qt 6/QML fork of CoreCtrl with an integrated LACT-derived GPU engine and an Adrenalin-style interface.

**Development version:** source import and release preparation are in progress. Feature parity with AMD's Windows application is not complete. No stable binary release is available yet.

Source code, upstream attribution, build instructions and the implementation roadmap are being prepared for upload. AMD Windows binaries and recovered proprietary resources are not distributed here.
