## Usage and accuracy

- Prefer the official AMD spelling **Adrenalin** (without the final “e”); the canonical product name is **AMD Software: Adrenalin Edition**.
- Describe Redline as an **alternative**, not an AMD port, a copy of proprietary code or an officially supported AMD application.
- The word *replacement* describes the long-term product goal, **not** verified feature-for-feature parity.
- Call out Linux driver, GPU and compositor limitations; distinguish implemented features from roadmap items.
- Keep preserved upstream files, contributor credits, copyright and third-party license notices intact.
- Use original Redline brand assets. Do not use AMD logos or imply AMD endorsement.
